# CP027 security

Authority: engineering authoring only, fence 1; runtime, production, provider effects, installs and container starts are not authorized. F04/F05/F06/F09 public exports are read-only inputs. Shared lock/policy/CI adoption and exact-head merge remain root-owned.

Per-app owner/migrator/runtime roles prevent application credentials from reading or mutating another application's database. Owners cannot log in, migrators explicitly assume only their own owner, runtime cannot assume owner or create schema/functions/temp objects. Public CONNECT/TEMP and public schema creation are revoked. Fully qualify ledger tables and keep pg_catalog first. Only scoped operational-ledger SELECT/INSERT and sequence USAGE are granted. Native application tables are never written by adapters. The database does not verify business approval, consent, F04 hashes, provider readback or external HOLD by itself.

TLS TCP requires SCRAM and client verify-full; non-TLS/unknown users/cross-db HBA paths reject. Exact private CIDRs remain unresolved, no permissive public HBA rule is supplied. Peer socket admin is confined to the isolated OS account; runtime sockets reject. Cipher/passfiles/certs are private mounts and file mode 0600, data/repositories 0700. Runtime harness creates only random synthetic secrets; raw pgBackRest/server logs and private files stay inside executor-owned output, never committed or printed as receipts.

Do not log SQL statements/binds/authentication input. The integration runner stores command argv with references to private files and output hashes, not raw payloads. Root must review and redact private logs before publication; hash-only receipts cannot independently prove semantics, so verifier inspects bounded private evidence. PostgreSQL logs can still contain unexpected sensitive metadata; empirical redaction tests remain NOT_RUN.

Resource/egress claims require actual cgroup v2/quota/namespace/seccomp/LSM/UID-map observation. Disk budgets include source, restored copy, usable and damaged repositories, WAL, secrets and logs. Exceeding the 2GiB proposal stops the rehearsal for measured expansion. No broad host discovery, pre-existing mounts, engines, production credentials or sockets are allowed. Native tests use a fresh nonroot guest and loopback inside that guest; root enforces denied external egress independently. Template network=none is intentionally unusable for cross-container client TCP until reviewed.

Unresolved immutable artifacts, full dependency closure, licenses, exact application compatibility, SBOM/scanner/DB identities and runtime receipts block adoption. No exception can waive those facts. pgvector is disabled pending explicit need and authenticated compatible build. Independent verifier and required exact-head reviewer/CI/controller merge gates remain mandatory. No worker result establishes acceptance, deployment or G02 authority.
